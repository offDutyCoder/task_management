# TaskApp - 初期要件メモ

## このドキュメントの位置づけ

このドキュメントは壁打ち・ブレストの成果物で、正式な仕様書ではありません。

---

## 背景・動機

- 社内でチームメンバーが何のタスクを担当しているか把握できていない
- セキュリティ・イントラネット制約により外部ツール（Jira, Asana等）の導入が難しい
- 自主開発によるスキルアップも目的

---

## 目指すもの

Redmineのチケット管理を参考にしつつ、**よりユーザーフレンドリー**なチーム共有タスク管理アプリ。
Redmineの「設定項目が多すぎて使いにくい」部分を解消することを意識する。

---

## 想定ユーザー・規模

- 初期：5人程度のチーム
- 将来：会社全体への展開を視野に入れる

---

## 技術スタック

| レイヤー | 技術 |
|---|---|
| バックエンド | ASP.NET Core (C#) |
| フロントエンド | Angular + Angular Material |
| データベース | SQL Server |
| 実行環境 | Windows Server + IIS |
| バックグラウンドジョブ | Hangfire または Quartz.NET（定期タスク生成に使用） |

> 既存システムはASP.NET無印だが、新規開発はASP.NET Coreで行う（現在の主軸・長期メンテ性・Angular Web APIとの相性が優れるため）

## コア機能

### 1. タスク管理

タスクはRedmineのチケットをモデルに、以下の属性を持つ。

| 属性 | 必須 | 備考 |
|---|---|---|
| タイトル | ○ | |
| 説明 | - | |
| 担当者 | - | 複数人割り当て可 |
| 期限日 | - | |
| ステータス | ○ | 管理者がアプリ全体で定義（下記参照） |
| 優先度 | - | 高 / 中 / 低 |
| ラベル・タグ | - | カテゴリ分け用（下記参照） |
| タスク種別 | ○ | 通常タスク / 定期タスク |
| 親タスク | - | ツリー構造の起点 |

**UX方針：**
- 必須項目は最小限（タイトル・ステータスのみ）
- 他の属性はデフォルト値を設定し、必要なときだけ入力

### 2. ステータス管理

- 管理者がアプリ全体で使用するステータスを定義する
- 全プロジェクト・全タスクで共通のステータスを使用
- 将来的にはプロジェクト単位のカスタマイズに拡張予定
- デフォルト例：未着手 / 進行中 / レビュー中 / 保留 / 完了

### 3. ラベル・タグ管理

- 管理者が公式タグを作成・管理する
- ユーザーは公式タグの中から選んで使用する
- ユーザーは管理者に新しいタグをリクエストできる
- タグの表記ゆれ・重複を防ぎ、検索精度を維持する

### 4. タスクのツリー構造（サブタスク）

- タスク → サブタスク → ... と階層的に展開可能
- チェックリスト型で進捗を管理
- プロジェクト単位の管理はこのツリー構造で実現する

### 5. タスクの割り当て

- タスクを複数のユーザーに割り当て可能
- 他者へのタスク振り分けが可能

### 6. 共有・公開範囲

- タスク単位で共有するメンバーを選択できる
- サブタスクは**親タスクの公開範囲を自動継承**する（毎回設定の手間を省く）
- 将来的にはユーザーの所属（部署・グループ）単位での共有設定も追加予定

### 7. 定期タスク（繰り返しタスク）

日常業務（掃除・点検など）を毎回手動登録しなくて済むよう、テンプレートから自動生成する。

**テンプレートに保存する内容：**
- タイトル・説明・担当者・優先度・ラベル・共有設定

**スケジュール設定：**

| 設定項目 | 例 |
|---|---|
| 繰り返し頻度 | 毎日 / 毎週◯曜日 / 毎月◯日 |
| 除外日 | 土日除く、祝日除く（祝日は別途設定） |
| 生成時刻 | 毎朝8:00 など |

**表示制御：**
- 一覧画面では定期タスクを**デフォルト非表示**
- フィルターで表示/非表示を切り替え可能
- 通常タスクの検索・絞り込み結果にノイズを混入させない

### 8. ユーザー管理・認証

- 管理者がIDとパスワードでアカウントを作成
- 自己登録は不可
- 各ユーザーは自分のプロフィール編集・パスワード変更が可能

### 9. 通知

- アプリ内通知のみ（メール・Slack連携は対象外）
- 通知例：自分へのタスク割り当て、期限超過など

## 画面構成イメージ

### トップ画面（ダッシュボード）

1. **マイタスク**：自分に割り当てられたタスク一覧（最優先表示）
2. **チーム共有タスク**：共有されているタスク一覧、誰が何を担当・消化中かを把握できる

### タスク一覧

- 絞り込み・検索機能（担当者・期限・ステータス・優先度・ラベルなど）
- フィルターは初期実装から含める
- 定期タスクはデフォルト非表示、フィルターで切り替え
