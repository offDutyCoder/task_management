# 要求内容 - タスク管理（CRUD・ツリー構造）

## 概要

チーム向けタスク管理アプリ「TaskApp」において、タスクの作成・参照・更新・削除（CRUD）と、
親タスク・サブタスクによるツリー構造管理機能を実装する。

## 背景

PRD §1 で定義された P0 必須機能のコア部分。ユーザー管理・認証基盤が完成したため、
次のステップとしてタスク本体の CRUD を実装する。
タスクにはステータス・優先度・担当者・ラベル・共有設定・親子関係を持たせる。

## 実装対象の機能

### 1. タスク CRUD
- タイトル・ステータス・優先度・説明・期限・担当者・ラベル・共有ユーザーを持つタスクを作成できる
- タスク一覧（ページネーション・フィルター・フリーワード検索）を取得できる
- タスク詳細（サブタスク一覧含む）を取得できる
- タスクを更新・削除できる

### 2. ツリー構造（親タスク・サブタスク）
- タスク作成時に `parentTaskId` を指定してサブタスクを作成できる
- サブタスクは親タスクの共有設定を自動継承する
- タスク詳細にサブタスク一覧を含める

### 3. 担当者管理
- タスクに複数ユーザーを担当者として設定できる

### 4. ラベル管理
- 管理者がラベル（名称・色）を作成・編集できる
- タスクにラベルを付与できる

### 5. 共有範囲
- タスクごとに閲覧可能なユーザーを指定できる
- 共有範囲外のユーザーは API レベルで 403 を受け取る

## 受け入れ条件

### タスク CRUD
- [ ] POST /api/tasks でタスクを作成できる（title 必須、他はオプション）
- [ ] GET /api/tasks で一覧取得できる（statusId/assigneeId/labelId/priority/search/page/pageSize）
- [ ] GET /api/tasks/{id} で詳細取得できる（subTasks 含む）
- [ ] PUT /api/tasks/{id} でタスクを更新できる
- [ ] DELETE /api/tasks/{id} でタスクを削除できる
- [ ] title が空・200文字超の場合は 400 を返す

### ツリー構造
- [ ] parentTaskId を指定するとサブタスクとして作成される
- [ ] サブタスク取得時は親タスクの TaskShare で公開可否を判定する
- [ ] GET /api/tasks/{id} のレスポンスに subTasks 一覧が含まれる

### 担当者
- [ ] タスク作成・更新時に assigneeIds を指定できる
- [ ] タスク詳細レスポンスに assignees（id, displayName）が含まれる

### ラベル
- [ ] GET /api/labels で有効ラベル一覧を取得できる
- [ ] 管理者のみ POST/PUT /api/labels が実行できる

### 共有範囲
- [ ] shareUserIds を指定していないタスクは作成者のみ閲覧できる
- [ ] 共有範囲外のユーザーが GET /api/tasks/{id} にアクセスすると 403

### セキュリティ
- [ ] 認証済みユーザーのみ /api/tasks エンドポイントにアクセスできる
- [ ] 管理者以外は POST/PUT /api/labels にアクセスできない

## スコープ外

- 定期タスク（RecurringTemplate）は別フェーズ
- アプリ内通知（Notification）は別フェーズ
- ラベルリクエスト機能（LabelRequest）は別フェーズ
- 担当者変更時の通知は別フェーズ
