# 要求内容 - ユーザー管理・認証

## 概要

チーム向けタスク管理アプリ「TaskApp」において、管理者によるアカウント発行・管理と、Cookie ベースの認証機能を実装する。
自己登録は禁止し、管理者が一元的にユーザーアカウントを管理する。

## 背景

社内イントラネット環境でのセキュリティ確保のため、外部認証サービスを使用せず ASP.NET Core Cookie 認証で実装する。
管理者のみがアカウントを発行できる運用ポリシーに基づき、ユーザー管理機能は管理者専用とする。

## 実装対象の機能

### 1. 認証（ログイン・ログアウト・パスワード変更）
- ID・パスワードによるログイン（Cookie 発行）
- ログアウト（Cookie 削除）
- ログイン中ユーザーによる自分のパスワード変更

### 2. プロフィール管理
- ログイン中ユーザーが自分の表示名を更新できる

### 3. ユーザー管理（管理者専用）
- 管理者がアカウントを作成できる（LoginId・パスワード・表示名・ロール）
- 管理者がアカウントの有効化・無効化を切り替えられる
- 管理者が既存ユーザー情報を更新できる（表示名・ロール・IsActive）
- ユーザー一覧を取得できる（管理者のみ）

## 受け入れ条件

### 認証
- [x] POST /api/auth/login に loginId・password を送ると HTTP-only Cookie が発行される
- [x] 認証失敗時は 401 を返す
- [x] 無効化アカウントではログインできない（401）
- [x] POST /api/auth/logout で Cookie が削除される
- [x] PUT /api/users/me/password で現在パスワード確認後に変更できる
- [x] 認証済みエンドポイントへの未認証アクセスは 401 を返す

### プロフィール管理
- [x] PUT /api/users/me/profile で自分の DisplayName を更新できる

### ユーザー管理（管理者）
- [x] POST /api/users でアカウントを作成できる（管理者のみ）
- [x] LoginId の重複時は 400 を返す
- [x] GET /api/users でアクティブ・非アクティブ含む全ユーザー一覧を取得できる（管理者のみ）
- [x] PUT /api/users/{id} でユーザー情報を更新できる（管理者のみ）
- [x] 管理者以外が管理者専用エンドポイントにアクセスすると 403 を返す

### セキュリティ
- [x] パスワードは BCrypt（コスト係数 12）でハッシュ化して保存する
- [x] HTTP-only + SameSite=Strict Cookie を使用する
- [x] 自己登録エンドポイントは存在しない

## 成功指標

- 全ユニットテスト・統合テストが通過する
- `npm run typecheck` でフロントエンドに型エラーがない
- `npm run lint` でフロントエンドに Lint エラーがない

## スコープ外

以下はこのフェーズでは実装しません:

- メール送信によるパスワードリセット（管理者が直接伝達する運用）
- OAuth / SSO 連携
- ユーザーの自己登録機能
- パスワードポリシーの詳細設定（最小文字数は 8 文字固定）
