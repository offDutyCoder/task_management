# 要求内容

## 概要

管理者がラベル（タグ）の追加・編集・有効化/無効化を行える管理画面と、一般ユーザーが新規ラベルを管理者にリクエストできる機能を実装する。

## 背景

- タスクに付与するラベルは管理者のみが定義できる（自由入力不可）
- タグの表記ゆれ・重複をシステムが防止する
- 一般ユーザーが新規ラベルを必要とする場合、管理者にリクエストを送ることができる

## 実装対象の機能

### 1. ラベル管理（管理者向け）

- ラベルの一覧表示（名前・カラーバッジ・有効/無効状態）
- ラベルの新規作成（名前・HEXカラーコード入力、重複チェック）
- ラベルの編集（名前・カラー・有効/無効の変更）
- カラーピッカー / プレビュー表示
- ダイアログはStatusDialogComponentと同パターン（MAT_DIALOG_DATA injection）

### 2. ラベルリクエスト管理（管理者向け）

- 一般ユーザーからのリクエスト一覧表示（要求者名・ラベル名・理由・ステータス・日時）
- リクエストの承認（→ 自動でラベルを作成）
- リクエストの却下
- フィルター（Pending / Approved / Rejected）

### 3. ラベルリクエスト送信（一般ユーザー向け）

- タスク一覧またはラベル一覧からリクエスト送信ダイアログを開く
- 希望するラベル名と理由を入力して送信
- 重複名チェック（既存ラベルと同名はリクエスト不可）

## 受け入れ条件

### ラベル管理（管理者）

- [ ] 管理者がタグ名（最大50文字）・HEXカラーコードを設定できる
- [ ] ラベル名の重複がある場合はエラーを表示する（バックエンドで検証）
- [ ] ラベルの有効/無効を切り替えられる（無効ラベルはタスクに付与できない）
- [ ] 編集ダイアログで既存の値が初期値として表示される

### ラベルリクエスト管理（管理者）

- [ ] 管理者がPendingなリクエスト一覧を確認できる
- [ ] 承認するとラベルが自動作成され、リクエストのステータスがApprovedになる
- [ ] 却下するとリクエストのステータスがRejectedになる

### ラベルリクエスト送信（一般ユーザー）

- [ ] 一般ユーザーがラベル名と理由を入力してリクエストを送信できる
- [ ] 既存ラベルと同名のリクエストはフロントエンドで警告する

## スコープ外

以下はこのフェーズでは実装しません:

- ラベルの削除（IsActiveフラグによる無効化のみ対応）
- リクエスト却下時のユーザー通知（通知機能は別フェーズ）
- 承認時の自動カラー付与（管理者がリクエスト承認後に色を設定する）
