# 要求内容 - ダッシュボード

## 概要

ログイン後の初期画面として、「マイタスク」と「チーム共有タスク」を一覧表示するダッシュボード機能を実装する。
期限超過タスクを視覚的に区別し、チームの作業状況をひと目で把握できるようにする。

## 背景

PRD §2 「ダッシュボード」 に定義されている P0 機能。
現状、ログイン後の初期画面が存在せず、`''` → `login` にリダイレクトされるのみで、ユーザーが作業を開始するための起点がない。
チームメンバーが朝に自分のタスクと期限を確認し、作業完了後にステータスを更新するワークフローを支える画面が必要。

## 実装対象の機能

### 1. マイタスクセクション
- 現在ログイン中のユーザーが担当者として割り当てられているタスクを一覧表示する
- 定期タスクはデフォルト非表示（フィルタートグルで切り替え可能）
- 期限超過タスクを視覚的に区別する（赤色ハイライト）

### 2. チーム共有タスクセクション
- ログイン中ユーザーが閲覧権限を持つすべてのタスクを一覧表示する
- 各タスクの担当者が表示される
- 定期タスクはデフォルト非表示
- 期限超過タスクを視覚的に区別する

### 3. ルーティングの更新
- ログイン後のリダイレクト先を `/dashboard` に変更する
- デフォルトルート `''` を認証済みユーザーには `dashboard` にリダイレクトする

## 受け入れ条件

### マイタスクセクション
- [ ] GET /api/dashboard を呼び出し、マイタスク一覧が取得できる
- [ ] タスクのタイトル・ステータス・優先度・期限が表示される
- [ ] 期限が今日より前のタスクが赤色でハイライトされる
- [ ] 定期タスクがデフォルト非表示になる
- [ ] 「定期タスクを表示」トグルで定期タスクの表示・非表示を切り替えられる

### チーム共有タスクセクション
- [ ] チーム共有タスクが担当者情報とともに表示される
- [ ] 期限が今日より前のタスクが赤色でハイライトされる
- [ ] 定期タスクがデフォルト非表示になる

### ルーティング
- [ ] ログイン成功後に `/dashboard` に遷移する
- [ ] `''` ルートが `/dashboard` にリダイレクトする（認証済みの場合）
- [ ] 未認証ユーザーは `/login` にリダイレクトされる（既存動作を維持）

### バックエンド API
- [ ] `GET /api/dashboard` が認証済みユーザーに対して 200 を返す
- [ ] レスポンスに `myTasks` と `teamTasks` が含まれる
- [ ] 未認証アクセスは 401 を返す

## 成功指標

- ダッシュボード表示が 2 秒以内に完了する（ネットワーク遅延除く）
- `npm run typecheck` で型エラーなし
- `npm run lint` で Lint エラーなし
- 全ユニットテスト・統合テストが通過する

## スコープ外

以下はこのフェーズでは実装しません:

- タスクカードのインライン編集
- ドラッグ＆ドロップによるステータス変更
- ダッシュボード上でのタスク新規作成（タスク一覧ページに誘導する）
- KPI 集計パネル（完了率・タスク数のグラフ等）
- カスタマイズ可能なウィジェット
